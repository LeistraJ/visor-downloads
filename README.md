# visor-downloads

Public DMG downloads for Visor.

Current release:
- `Visor.dmg`

## Install

1. Download `Visor.dmg`.
2. Open the DMG and drag Visor into your `Applications` folder.
3. Open Visor from `Applications`.
4. If macOS blocks the first launch, open `System Settings` > `Privacy & Security`, scroll to the security message for Visor, and click `Open Anyway`.
5. Return to Visor and confirm `Open` when prompted.
6. If Visor asks for any additional permissions on first launch, allow them in `System Settings` > `Privacy & Security` so the app can work correctly.
